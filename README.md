Project Overview
This repository contains the source code for the first formative assessment, covering console applications and Windows Forms development in C#.

Project Structure:

Section A: Short Programming Tasks
Question 1 (Student Marks): Located in the /DigitalIdentityProcessor_SectionB_Question_1 folder. This program captures student names and marks, calculates averages, and determines PASS/FAIL status.

Question 2 (ATM System): Located in the root directory (Program.cs). This console application simulates a basic ATM with deposit, withdrawal, and balance check functions.

Question 3 (Language Selection): Located in the root directory. A Windows Forms application for selecting and displaying programming language details.

Section B: Long Programming Tasks
Question 1 (Emfuleni Municipality Console App): Located in the root directory. This application implements a Queue (FIFO) system to manage resident service requests, calculating urgency scores and generating reports.

Question 2 (Digital Identity Processor): The core logic is in CitizenProfile.cs and the user interface is in Form1.cs. This Windows Forms app extracts birth dates from SA ID numbers and validates citizen profiles using Encapsulation.

Technical Implementation
Language: C#

Framework: .NET Framework / Windows Forms

Key Concepts: Object-Oriented Programming (OOP), Encapsulation, Queue Data Structures (FIFO), and Data Validation.

How to Run
Clone the repository.

Open the solution file (.sln) in Visual Studio.

Press F5 to build and run the applications.
